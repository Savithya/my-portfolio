# Savithya Muthunima — Personal Portfolio Website

Modern, highly interactive, visually striking, and fully responsive personal developer portfolio website for **Savithya Muthunima**, an IT Undergraduate & Computer Science & AI Student.

Built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## 🌟 Key Features

- **Global UI/UX Design System**:
  - Dark Charcoal & Near-Black Palette (`#060914`, `#0F172A`, `#151D2E`, `#293449`).
  - Gradient accents (`#3B82F6` Blue, `#A855F7` Purple, `#22D3EE` Cyan).
  - Subtle glassmorphism, soft ambient glow, and micro-interactions.
  - Three fully functional appearance modes: **Dark (default)**, **Light**, and **System Preference**.

- **Interactive Navigation Bar**:
  - Sticky glassmorphic design with active section spy highlighting.
  - One-click CV download button.
  - Accessible mobile drawer menu and theme toggle.

- **Hero Section**:
  - Animated rotating titles (*Aspiring Software Developer*, *AI & Machine Learning Enthusiast*, *Cybersecurity Researcher*, *Technology Enthusiast*).
  - Direct call-to-actions, social media integration, and tech badge visuals.

- **About Me**:
  - Academic and career journey narrative.
  - 3 highlight cards: *Academic Development*, *Practical Projects*, and *Career Development*.
  - Core domain tags.

- **My Skills — Technologies & Tools (Reference Design)**:
  - 4-column responsive grid layout with rounded technology containers.
  - Authentic technology logos (*Python, JavaScript, TypeScript, C++, CSS, SQL, MySQL, PL/pgSQL, Machine Learning, Data Structures, Algorithms, VS Code, Anaconda, Jupyter Notebook, GitHub*).
  - Category filter tabs (*All Skills, Languages, Web Development, Databases, AI & Data, Tools, Core Concepts*).
  - Subtle lift, soft glow, and icon scaling on hover.

- **Education Timeline**:
  - Vertical animated timeline with degree status, institutions, and descriptions.
  - BSc (Hons) Computer Science with AI (Currently Pursuing), Pearson BTEC Computing, Level 3 IT Diploma (UK), and Certificate Course in Spoken English.

- **Featured Projects & Academic Research**:
  - **Cyber Campus — Cybersecurity Awareness Platform** (Web Development & Cybersecurity).
  - **Academic Research: Impact of Social Engineering Threats on User Privacy** (Python, Anaconda, Jupyter Notebook).
  - Interactive project detail modal with detailed architectural highlights and repository links.

- **Research & Innovation**:
  - 4 threat category cards (*Phishing, Pretexting, Impersonation, Online Scams & Malicious Links*).
  - Research methodology overview and student privacy analysis.

- **Professional Skills & Certifications**:
  - 5 soft skills: *Teamwork, Time Management, Leadership, Effective Communication, Critical Thinking*.
  - Academic certifications and language proficiency (*English, Sinhala*).

- **Contact Form & CV Download**:
  - Form validation with accessible error indicators, honeypot anti-spam, and email client launcher.
  - Verified CV download endpoint (`/Savithya_Muthunima_CV.pdf`).

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/), [React Icons](https://react-icons.github.io/react-icons/) (Simple Icons, VS Code Icons)
- **Deployment**: [Vercel](https://vercel.com/)

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
